# Attribution

Garmin RepTrace is an independent strength-training application derived from
[Garmin-Grafana](https://github.com/arpanghosh8453/garmin-grafana), created by Arpan Ghosh.
The inherited Garmin collection and InfluxDB integration retain their upstream provenance.

The original BSD 3-Clause copyright notice and license are preserved unchanged in
[LICENSES/BSD-3-Clause.txt](LICENSES/BSD-3-Clause.txt). Inherited code retains those notices
and its original BSD permissions.
The Garmin RepTrace application adds a dedicated training interface, exercise analytics,
weekly muscle views, reversible corrections, progression planning, Garmin workout
editing, nutrition, exports, and optional Telegram coaching/reporting.

Garmin RepTrace is a community project, not an official Garmin product, and does not imply
endorsement by Garmin or the upstream project's contributors.
